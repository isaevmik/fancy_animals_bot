### Описание
Подсервис server инкапсулирует в себе логику хранения и выдачи информации для дальнейшего её сбора в UserStorys на UI в виде Telegram бота.

## bot

### Описание
Telegram бот предоставляет нам UI со всеми необходимыми пользовательскими сценариями

### Функциональные требования
#### Карточка информации о приюте
#### Карточка контактов приюта
#### Карточка как поддержкать приют
#### Каталог с карточками животных
- keySet пагинация
- наличие фото и краткого описания
- нужен ли особый уход животному
#### Функционал администрирования
Он включает в себя возможность редактирования каталога и всех карточек (информация о приюте, контактная информация, информация о поддержке)
#### Ролевая модель
Ролевая модель с базовыми ролями: клиент, администратор
