# fancy_animals_bot

## server

### Описание
Подсервис server инкапсулирует в себе логику хранения и выдачи информации для дальнейшего её сбора в UserStorys на UI в виде Telegram бота.

### Функциональные требования
#### CRUD с информацией о приюте
#### CRUD с контактной информацией
#### CRUD с карточкой о поддержке приюта
#### CRUD для каталога животных
#### CRUD с ролевой моделью

### Нефункциональные требования

## bot

### Описание
Telegram бот предоставляет нам UI со всеми необходимыми пользовательскими сценариями

### Функциональные требования
#### Карточка информации о приюте
#### Карточка контактов приюта
#### Карточка как поддержкать приют
#### Каталог с карточками животных
- keySet пагинация
- наличие фото и краткого описания
- нужен ли особый уход животному
#### Функционал администрирования
Он включает в себя возможность редактирования каталога и всех карточек (информация о приюте, контактная информация, информация о поддержке) для пользователей с ролью `administrator` из таблицы `user_roles`.

Это будет выглядеть, как наличие дополнительных кнопок редактирования и добавления в интерфейсе при выполнении команды инициализации.

#### Ролевая модель
MVP ролевая модель с базовыми ролями: клиент, администратор

| Роль          | Редактирование карточки о приюте | Редактирование контактной карточки  | Редактирование карточки с поддержкой | Управление каталогом |
|---------------|----------------------------------|-------------------------------------|--------------------------------------|----------------------|
| Администратор | True                             | True                                | True                                 | True                 |
| Пользователь  | False                            | False                               | False                                | False                |
